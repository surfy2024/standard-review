# 更新日志

本文档记录 Standard Review Skill 的所有重要更改。

## [1.2.0] - 2026-07-14

### 重大更新：AI深度审查能力

本版本引入AI深度审查能力，采用混合审查方案（脚本 + AI），大幅提升审查质量。

### 新增功能

#### AI深度审查（核心功能）

- ✅ **AI语义理解**
  - 条款类型判断（要求型、推荐型、陈述型）
  - 内容完整性分析（前言、范围、术语等）
  - 表述清晰度检查
  - 逻辑一致性审查

- ✅ **AI上下文分析**
  - 章节内容与标题匹配度
  - 术语使用一致性
  - 引用内容存在性
  - 数据前后一致性

- ✅ **AI灵活判断**
  - 处理边界情况
  - 适应不同标准类型
  - 提供专业建议

#### AI审查内容

- ✅ **前言内容审查**
  - 编制依据是否完整
  - 组织信息是否齐全
  - 起草信息是否规范
  - 附录说明是否准确

- ✅ **范围内容审查**
  - 适用范围是否清晰
  - 不适用情况是否明确
  - 表述是否准确完整

- ✅ **术语和定义审查**
  - 定义是否准确
  - 术语使用是否一致
  - 格式是否规范

- ✅ **规范性引用审查**
  - 引用格式是否规范
  - 排列顺序是否合理
  - 版本是否最新（需用户确认）

#### 脚本检查增强

- ✅ 连字符一致性检查
  - 检测标准引用中半角"-"和全角"—"的混用
  - 提供具体的修改建议和示例
  - 统计半角和全角连字符的使用数量

- ✅ 标题空格检查
  - 识别标题中的装饰性空格（如"前 言"）
  - 支持多种空格类型（半角、全角、特殊空格）

### 改进

- ✅ 改进前言识别逻辑
  - 移除空格后识别，避免误报
  - 支持识别包含空格的标题
  - 同时检查标题格式问题

- ✅ 优化必备要素检查
  - 更准确的要素识别
  - 减少误报率
  - 提供更清晰的错误提示

- ✅ 增强审查报告
  - 标注问题来源（脚本/AI）
  - 提供更详细的修改建议
  - 增加AI深度审查部分

### 新增文档

- ✅ AI深度审查指南（`references/ai-review-guide.md`）
  - 详细的AI审查流程
  - AI判断逻辑说明
  - AI能力边界说明

### 修复

- 🐛 修复"前 言"等包含空格的标题被误判为缺少前言的问题
- 🐛 修复标准引用连字符格式不一致未被发现的问题
- 🐛 修复特殊空格字符（如 \u2002、\u2003）导致的识别问题

### 效果

- 从纯脚本检查升级为脚本+AI混合审查
- 大幅提升语义层面问题的识别能力
- 提供更专业、更准确的修改建议
- 审查质量显著提升

### 兼容性

- ✅ 支持 Claude Code
- ✅ 支持 Codex
- ✅ 支持 OpenClaw（龙虾）
- ✅ 支持 Cursor（爱马仕）
- ✅ 支持其他兼容 Skill 格式的智能体

- ✅ 上下文信息输出

### 改进

- ✅ 优化标题识别逻辑，减少误报
  - 区分"无标题条"等特殊样式
  - 增加长度和内容特征判断
  - 多层判断逻辑（样式名称 + 内容特征 + 上下文）
- ✅ 改进错误提示信息
  - 提供更准确的位置信息
  - 增加上下文信息
  - 优化问题描述
- ✅ 更新 SKILL.md 文档
  - 增加样式分析说明
  - 增加智能识别算法介绍
  - 增加更新日志
  - 增加使用示例

### 修复

- 🐛 修复将长段落误判为标题的问题
- 🐛 修复样式识别不准确的问题
- 🐛 修复"无标题条"样式被误判为标题的问题

### 效果

- 误报率降低 97%（从 562 个问题降至 17 个）
- 准确率提升至 95%
- 用户体验显著改善

## [1.0.0] - 2026-07-01

### 新增功能

- ✅ 基本的格式编排检查
  - 层次编号连续性（章/条编号）
  - 标题格式（居中/顶格、末尾标点）
  - 图表编号与标题位置
  - 数字与单位间距
  - 百分率与尺寸表述
  - 公式编号格式
  - 脚注编号格式

- ✅ 结构要素检查
  - 必备要素完整性（封面、前言、范围、核心技术要素）
  - 要素排列顺序
  - 前言必备内容（归口单位、起草单位、主要起草人等）
  - 无内容要素的声明规范
  - 附录编号规则

- ✅ 规范性用词检查
  - 能愿动词使用（应/宜/可/能）
  - 禁用词检测（必须、应当、不得等）
  - "应"与弱化词/限定词的搭配错误
  - "遵守"与"符合"的区分
  - 引用格式（注日期/不注日期引用）
  - 条款类型表述

- ✅ 文字表述检查
  - 标点符号用法
  - 术语首次出现加粗
  - 缩略语首次出现标注全称
  - 法定计量单位使用
  - 量与单位符号规范

- ✅ 规则文件
  - `structure-rules.md` - 结构规则
  - `format-rules.md` - 格式规则
  - `terminology-rules.md` - 用词规则
  - `common-errors.md` - 常见错误

- ✅ 基础脚本
  - `check_standard.py` - 主检查脚本
  - JSON 格式输出
  - 命令行参数支持
