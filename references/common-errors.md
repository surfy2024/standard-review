# GB/T 1.1-2020 常见错误清单与审查检查表

## 错误严重等级定义

| 等级 | 标识 | 定义 | 处理建议 |
|------|------|------|----------|
| **错误** | ERROR | 违反 GB/T 1.1-2020 强制性规定，可能导致文件无法通过审查 | 必须修改 |
| **警告** | WARNING | 不符合推荐性要求或可能引起歧义，建议修改 | 建议修改 |
| **建议** | SUGGESTION | 可优化但非必须，提升文件质量 | 可选修改 |

## 高频错误模式

### 一、结构类错误

| 错误编号 | 错误描述 | 严重等级 | 典型示例 | 正确做法 |
|---------|---------|---------|---------|---------|
| S001 | 缺少必备要素 | ERROR | 无"前言"章节 | 补充前言要素 |
| S002 | 要素顺序错误 | ERROR | "范围"在"前言"之前 | 调整为：封面->前言->范围->... |
| S003 | 层次编号不连续 | ERROR | 章号从1跳到3（缺少第2章） | 补充缺失章节或重新编号 |
| S004 | 条编号孤立 | WARNING | 只有"3.1"而无"3.2" | 改为在章下设段，或补充其他条 |
| S005 | 款/项无归属 | ERROR | 破折号引导的款直接出现在章下 | 将款移至某一条下 |
| S006 | 附录编号使用I或O | ERROR | 附录I、附录O | 跳过I和O，使用附录H、附录J |
| S007 | 无内容要素未声明 | ERROR | 无规范性引用文件时直接跳过 | 写明"本文件没有规范性引用文件。" |
| S008 | 前言缺少必备内容 | ERROR | 前言未说明归口单位 | 补充归口单位、起草单位等 |
| S009 | 引言包含规范性条款 | ERROR | 引言中出现"应……"要求 | 将规范性内容移至正文 |

### 二、格式类错误

| 错误编号 | 错误描述 | 严重等级 | 典型示例 | 正确做法 |
|---------|---------|---------|---------|---------|
| F001 | 标题末尾有标点 | ERROR | "3.1 总则：" | 删除标点："3.1 总则" |
| F002 | 数字与单位无空格 | WARNING | "20mm" | 改为"20 mm" |
| F003 | 尺寸表述不规范 | WARNING | "80x25x50 mm" | 改为"80 mm x 25 mm x 50 mm" |
| F004 | 百分率公差格式错误 | ERROR | "65+/-2%" | 改为"(65+/-2)%" |
| F005 | 图编号不连续 | ERROR | 图1后接图3 | 重新编号或补充图2 |
| F006 | 表编号不连续 | ERROR | 表1后接表3 | 重新编号或补充表2 |
| F007 | 分表编号 | ERROR | "表2a""表2b" | 合并为一个表或分别编号为表2、表3 |
| F008 | 图题位置错误 | WARNING | 图题在图上方 | 图题应在图下方 |
| F009 | 表题位置错误 | WARNING | 表题在表下方 | 表题应在表上方 |
| F010 | 目次使用阿拉伯数字 | ERROR | 目次页码为1、2、3 | 改为罗马数字I、II、III |
| F011 | 公式编号无括号 | WARNING | 公式3 | 改为"公式(3)" |
| F012 | 脚注编号格式错误 | ERROR | 图脚注使用数字编号 | 改为字母编号：a、b、c |

### 三、用词类错误

| 错误编号 | 错误描述 | 严重等级 | 典型示例 | 正确做法 |
|---------|---------|---------|---------|---------|
| T001 | 使用禁用能愿动词 | ERROR | "必须……""应当……" | 改为"应……" |
| T002 | "应"与弱化词搭配 | ERROR | "应尽量……""应考虑……" | 改为"宜尽量……""宜考虑……" |
| T003 | "应"与限定词搭配 | WARNING | "一般应……""通常应……" | 改为"一般宜……""通常宜……" |
| T004 | "遵守""符合"混用 | WARNING | "产品应遵守……要求" | 改为"产品应符合……要求" |
| T005 | 引用格式错误 | ERROR | "GB/T XXXXX-2020第3页" | 不应引用页码，改为"GB/T XXXXX-2020第3章" |
| T006 | 注日期引用格式错误 | ERROR | "GB/T XXXXX:2020" | 改为"GB/T XXXXX-2020"（用一字线） |
| T007 | 条文脚注含要求条款 | ERROR | 脚注中出现"应……" | 条文脚注只能含陈述性内容 |
| T008 | "概述"含要求条款 | ERROR | "概述"章节中出现"应……" | "概述"只能含陈述型条款 |
| T009 | 术语定义含要求 | ERROR | "XX是指应……的设备" | 术语定义不应含要求型条款 |

### 四、文字类错误

| 错误编号 | 错误描述 | 严重等级 | 典型示例 | 正确做法 |
|---------|---------|---------|---------|---------|
| W001 | 中文正文使用半角标点 | WARNING | 使用半角逗号"," | 改为全角逗号"，" |
| W002 | 公式中使用全角标点 | WARNING | 公式中使用全角括号 | 改为半角标点 |
| W003 | 术语首次出现未加粗 | SUGGESTION | "可靠性是指……" | 改为"**可靠性**是指……" |
| W004 | 缩略语首次出现未标注全称 | WARNING | "使用PLC进行控制" | 改为"使用可编程逻辑控制器（PLC）进行控制" |
| W005 | 使用非法定计量单位 | ERROR | 使用"斤""亩" | 改为法定单位"kg""平方米" |

## 审查检查表

### 结构审查检查表

- [ ] 封面是否存在
- [ ] 前言是否存在
- [ ] 前言是否包含：起草依据、提出部门、归口单位、起草单位、主要起草人
- [ ] 范围是否存在
- [ ] 规范性引用文件是否存在（无则声明）
- [ ] 术语和定义是否存在（无则声明）
- [ ] 核心技术要素是否存在
- [ ] 要素顺序是否正确
- [ ] 章编号是否从1开始连续编号
- [ ] 条编号是否连续
- [ ] 是否存在孤立的条（只有X.1而无X.2）
- [ ] 款是否隶属于条
- [ ] 项是否隶属于款
- [ ] 附录编号是否跳过I和O
- [ ] 引言是否包含规范性条款（如有引言）

### 格式审查检查表

- [ ] 章标题是否居中
- [ ] 条标题是否顶格
- [ ] 标题末尾是否无标点
- [ ] 数字与单位间是否有空格
- [ ] 尺寸表述是否规范（每个量带单位）
- [ ] 百分率公差是否用括号
- [ ] 图编号是否连续
- [ ] 表编号是否连续
- [ ] 是否存在分表（表2a等）
- [ ] 图题是否在图下方
- [ ] 表题是否在表上方
- [ ] 目次是否使用罗马数字
- [ ] 公式编号是否有括号
- [ ] 图脚注是否使用字母编号
- [ ] 表脚注是否使用字母编号
- [ ] 条文脚注是否使用数字编号

### 用词审查检查表

- [ ] 是否使用"必须""应当"等禁用词
- [ ] "应"是否与弱化词搭配
- [ ] "应"是否与限定词搭配
- [ ] "遵守""符合"是否正确区分
- [ ] 引用是否提及页码
- [ ] 注日期引用格式是否正确（一字线）
- [ ] 条文脚注是否含要求条款
- [ ] "概述"章节是否含要求条款
- [ ] 术语定义是否含要求条款
- [ ] 注/示例是否含要求条款

### 文字审查检查表

- [ ] 中文正文是否使用全角标点
- [ ] 公式是否使用半角标点
- [ ] 术语首次出现是否加粗
- [ ] 缩略语首次出现是否标注全称
- [ ] 是否使用法定计量单位
- [ ] 量符号是否用斜体
- [ ] 单位符号是否用正体

## 报告模板

审查报告应包含以下内容：

1. **文件信息**：文件名称、审查日期、审查依据
2. **审查结果概览**：按严重等级统计问题数量
3. **详细问题清单**：按严重等级分组，每条含问题编号、位置、描述、修改建议
4. **修改优先级建议**：错误->警告->建议
